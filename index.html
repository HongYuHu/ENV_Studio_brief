直接 Import
進 Stage，支援多選

選好資產後，點擊 Import to Stage 即可將 USD Reference 匯入 Houdini Solaris。支援一次多選，批次匯入多個資產。

注意 Import 時會自動複製一份 USD 檔案到專案目錄下，確保送上 Deadline 農場後不會因為路徑問題造成掉檔。
